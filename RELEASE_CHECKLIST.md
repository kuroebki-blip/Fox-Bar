# FO’X — чек-лист релиза

## До изменения

- [ ] Определён затронутый компонент.
- [ ] Получена фактическая production-версия компонента.
- [ ] Создана отдельная ветка.
- [ ] Для таблицы создана новая версия или копия.
- [ ] Setup-функции не запускаются без прямого подтверждения.

## Перед публикацией

- [ ] Diff минимален и не затрагивает несвязанные компоненты.
- [ ] Назначена новая версия.
- [ ] Обновлён `CHANGELOG.md`.
- [ ] Выполнены профильные автоматические тесты.
- [ ] Записаны сценарии, которые требуют пользовательского теста.
- [ ] Нет `PASTE_...`, секретов, `.env` или экспорта Script Properties.
- [ ] Сохранены необходимые публичные Web App URL и frontend-конфиги.
- [ ] Нет удаления формул, значений, стилей или setup-функциями.
- [ ] Подготовлен точный откат: commit/frontend и Apps Script version/backend.

## После публикации

- [ ] GitHub Pages/Apps Script deployment завершён успешно.
- [ ] Публичная версия или `ping` соответствует релизу.
- [ ] Выполнен smoke-тест.
- [ ] Пользовательский тест не объявлен успешным, пока пользователь его не подтвердил.
- [ ] После подтверждённого релиза обновлён `PROJECT_STATE.md`.
