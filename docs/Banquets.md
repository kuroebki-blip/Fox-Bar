# Банкеты

## Поток данных

Mini App → Cloudinary → URL → Banquets Apps Script → Google Sheets.

Фото не должно передаваться через Apps Script/base64. В таблице хранится URL и, при необходимости, public ID.

## Правила

- На одну дату допускается несколько банкетов.
- Одна позиция может участвовать в нескольких банкетах.
- Пользовательские статусы: «Актуальный», «Пройден», «Отменён».
- «Заказ отправлен» снимает резерв, но не удаляет банкет.
- Backend не менять для чисто frontend-задачи.
- `setupBanquetsBackend()` не запускать без прямого подтверждения пользователя.

## Состояние

Production frontend находится в `index.html`. Фактический production исходник Banquets Apps Script в `main` отсутствует; версия неизвестна и требует проверки deployment. Reference-файлы в рабочих ветках нельзя считать production.

## Требующие проверки проблемы

- несколько банкетов на одну дату;
- снятие резерва после завершения или отправки заказа;
- добавление новой позиции в банкетный резерв.

Проверять на копии таблицы и без setup-функций.
