# Tatooine RBAC

Источник истины для пользователя — проверенный Telegram user ID. Роль хранится в служебном листе `Tatooine_Пользователи`; изменения фиксируются в `Tatooine_АудитРолей`.

Первичная настройка: до первого входа superadmin добавьте Telegram ID через Script Properties `TATOOINE_RBAC_BOOTSTRAP_SUPERADMIN_IDS` (одно или несколько значений через запятую). Bootstrap действует только пока в листе нет superadmin. Затем откройте Tatooine и раздел «Сотрудники и роли» — листы создадутся безопасно, а bootstrap-пользователь будет сохранён как superadmin.

Пользователь без назначенной роли получает `employee`. После появления служебного листа первый `currentUser` bootstrap автоматически сохраняет пользователя с этой ролью, без отдельного запроса. Нынешние кассовые сценарии сохраняют доступ для всех проверенных Telegram-пользователей. `FOX_RECEIPTS.adminTelegramIds` относится к FO’X-банкетам и не используется для Tatooine RBAC.

Scope по локации пока не реализован: в модели роли нет утверждения, что менеджер должен видеть все будущие подразделения. Для будущих модулей добавляйте scope отдельно рядом с permission checks.
