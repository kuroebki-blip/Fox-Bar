# Telegram

## Маршруты

- FO’X работает через основной Telegram-бот и Mini App.
- Tatooine использует отдельный бот и отдельный frontend.
- Общий cash backend выбирает маршрут по приложению.

Токены и целевые чаты хранятся только в Apps Script Script Properties. Значения не должны попадать в Git или документацию.

## Доступ

FO’X использует административные Telegram ID для защищённых действий. Кассовый отчёт Tatooine должен быть доступен пользователю с валидной Telegram Mini App-авторизацией без прежнего allowlist; возвращать allowlist только по прямому указанию владельца.

## Проверка

- авторизация init data;
- правильный бот и чат для каждого приложения;
- форматирование и custom emoji;
- повторная отправка исправленного отчёта;
- отсутствие токена в frontend и логах.
