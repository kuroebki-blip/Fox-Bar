# OCR

## Поток

Frontend нормализует изображения → Apps Script отправляет запрос Gemini → backend валидирует и нормализует результат → пользователь проверяет данные перед отправкой.

## Кассовый отчёт

- Каждая исходная фотография становится одной монтажной страницей 2×2 с перекрытиями.
- Число изображений в основном запросе не увеличивается.
- Один физический слип на соседних секторах нельзя учитывать дважды.
- Главный терминальный итог берётся из `Количество оплат → На сумму`.
- «Оплата QR» учитывается при проверке.
- При сомнении между `6` и `8` результат должен быть помечен для ручной проверки, а не подогнан под iiko.
- iiko 041 является единственным источником iiko-строк финального отчёта.

## Ограничения

Gemini может ошибаться на бликах, сгибах, низком разрешении и мелкой термопечати. Автоматические тесты проверяют логику, но реальная точность требует пользовательского теста на исходных фото.
