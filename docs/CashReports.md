# Кассовые отчёты

## Приложения

- FO’X: кассовый отчёт внутри основной Mini App.
- Tatooine: отдельная Mini App и отдельный Telegram-бот.
- OCR/backend общий, шаблоны и маршруты Telegram различаются.

## Источники

- iiko: только отчёт 041.
- Терминальный итог: блок `Количество оплат → На сумму`.
- «Оплата QR» обязательна для проверки.
- Инкассация: только надпись на конверте, формат `значение (значение в скобках)`.
- Фото не сохраняются в Google Sheets.

## Tatooine

Финальный шаблон содержит общую выручку, безнал, нал, онлайн-кассу 2, EatAndSplit, Яндекс Еду, расход, инкассацию, неизменный размен и опциональные предоплаты. Стандартный размен — `100 000`. Если предоплат нет, блок предоплат и `Итого` не выводятся.

## Надёжность

- Пустые обязательные строки FO’X остаются в сообщении.
- Исправленный отчёт можно отправлять повторно.
- Даты терминальных слипов и конверта не заменяют дату iiko 041.
- Для текущего montage-релиза живой тест точности цифр ещё требуется.
