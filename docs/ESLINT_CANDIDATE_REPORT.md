# ESLint candidate — диагностический отчёт

Дата: 26 июля 2026 года.

## Область проверки

Команда:

```sh
pnpm lint:check
```

Проверяются только самостоятельные browser scripts:

- `tatooine/app.js`;
- `tatooine/config.js`.

Не проверяются:

- встроенный JavaScript в `index.html` — для него нужен отдельный HTML processor и самостоятельный этап;
- внешние CDN-скрипты;
- `node_modules`, `coverage`, `dist`, `build`;
- minified, архивные и HEIC-файлы.

Инструменты candidate: ESLint `10.8.0`, globals `17.7.0`, pnpm `11.9.0`. Минимальная поддерживаемая версия Node определяется полем `engines` в `package.json`.

## Результат

`tatooine/config.js` прошёл без сообщений. В `tatooine/app.js` найдено одно срабатывание:

| Категория | Место | Правило | Описание |
| --- | --- | --- | --- |
| Потенциальный баг | `tatooine/app.js:16:46` | `no-promise-executor-return` | Стрелочный executor `Promise` неявно возвращает результат `setTimeout`; Promise это значение не использует. Требует отдельного решения пользователя. |

### Синтаксические ошибки

Не обнаружены.

### Потенциальные баги

Одно срабатывание `no-promise-executor-return`. Рабочий код не изменён.

### Устаревший код

Не обнаружен выбранным набором правил. Специализированная проверка browser compatibility не подключалась.

### Стилевые замечания

Не проверялись: stylistic-правила и автоформатирование намеренно не подключены.

## Статус команды

Команда завершилась с кодом `1` из-за одного ESLint error. Это зафиксированный baseline candidate, а не регрессия от изменения приложения.

## Риски и следующий этап

- Текущая проверка не охватывает встроенный JavaScript FO’X в `index.html`.
- Исправлять найденную строку можно только после подтверждения пользователя и в отдельном изменении рабочего кода.
- Следующий безопасный этап: решить судьбу единственного срабатывания, затем отдельно оценить HTML processor для `index.html`.
- Prettier и Playwright в этот candidate не входят.
