# Безопасность FO’X

## Никогда не коммитить

- Gemini API Key и другие API-ключи.
- Telegram Bot Token.
- Cloudinary API Secret.
- Пароли, приватные ключи, session cookies.
- `.env`, дампы окружения и экспорт Script Properties.
- Содержимое рабочих Google Sheets.

Секреты Apps Script должны храниться только в Script Properties. Во frontend допустимы публичные Web App URL, Cloudinary cloud name и unsigned upload preset.

## Проверка перед коммитом

Проверить имена и типичные форматы без вывода значения целиком:

```sh
git diff --cached --name-only
rg -l -i 'api[_-]?key|bot[_-]?token|api[_-]?secret|private[_-]?key|password|script properties' .
git log -p --all -- . ':!*.zip'
```

Совпадение имени переменной не является утечкой. Проверяющий сообщает только путь, тип риска и рекомендуемую ротацию — найденное значение целиком не копируется в issue, PR или чат.

Если обнаружен реальный секрет:

1. Не публиковать commit.
2. Немедленно отозвать или ротировать секрет у провайдера.
3. Удалить значение из рабочей копии и истории согласованным способом.
4. Проверить логи доступа.
5. Зафиксировать инцидент без раскрытия значения.

## Текущее состояние

Документационный Developer Kit не содержит значений секретов. Финальная проверка всей ветки обязательна перед Pull Request.
